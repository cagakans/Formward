# Formward

Formward is a fitness and body-progress tracking Android application developed for the MIS 49M final project.

## Description

The app helps users track daily fitness discipline through missions, workout planning, nutrition tracking, progress measurements, body fat estimation and photo check-ins. It calculates a daily Form Score based on workout or recovery completion, nutrition logging and mission progress.

## Features

- Initial profile setup
- Daily form score, weekly score, and streak tracking
- Daily mission checklist
- Workout planner and workout history
- Nutrition targets and daily intake tracking
- Body fat estimation and progress measurement history
- Photo check-in system
- Profile management
- Firebase data synchronization

## Technologies

- Kotlin
- Android Studio
- Jetpack Compose
- Navigation Compose
- SharedPreferences
- Firebase Firestore

## Note

Progress photos are stored locally on the device. Firebase is used to sync user profile data, scores, workout data, nutrition data, progress data and photo metadata.
